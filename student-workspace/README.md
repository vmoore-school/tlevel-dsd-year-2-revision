# Student Workspace

**Your** working area. Everything else in the repo is reference material. Copy templates in here and
fill them in.

| Folder | Put here |
|---|---|
| `notes/` | Your own revision notes, one file per lesson (e.g. `01.05-methodologies.md`) |
| `lesson-work/` | Completed lesson activities and exercises |
| `practice/` | Code experiments and practice projects |
| `mock-osp/` | A full mock OSP run, laid out like the real submission |
| `placement/` | Your industry placement logbook and hours |

Track your progress in [`progress-tracker.csv`](../progress-tracker.csv) (rate your confidence 1-5
per topic) or tick off topics in [`CHECKLIST.md`](../CHECKLIST.md).

> **Sharing this repo as a template?** Clear this folder first, or keep it to `.gitkeep` files.
