## Mock run checklist
- [ ] Task 1 done in the time allowed, with research notes as facts and figures only
- [ ] Task 1 evidence frozen (no edits after this point)
- [ ] Task 2 prototype uses 2+ languages; test log, assets log and development log kept up to date
- [ ] Task 3a demos for both audiences; feedback recorded in an analysable format
- [ ] Task 3b written in 2 hours with no internet
- [ ] Every file named correctly and exported to PDF where required
