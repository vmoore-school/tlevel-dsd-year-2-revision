# Survey: [Prototype name] Feedback

**Audience:** · **Delivered via:** Google Forms / Microsoft Forms · **Consent statement:** _"Your answers are anonymous and will only be used to improve this prototype..."_

| # | Question | Type | Linked requirement / KPI |
|---|---|---|---|
| 1 | How easy was it to book a session? (1 = very hard, 5 = very easy) | Likert 1-5 | UAC1 |
| 2 | How long did it take you to make a booking? | Multiple choice (<1 min / 1-3 min / >3 min) | KPI: booking under 2 min |
| 3 | Did anything stop you completing a task? | Yes/No + open | FR1-FR5 |
| 4 | How clear was the text and layout? (1-5) | Likert | NFR accessibility |
| 5 | Which feature was most useful? | Single choice | |
| 6 | What one thing would you improve? | Open | Next iteration |
| 7 | Which device did you use? | Single choice | NFR compatibility |
| 8 | How likely are you to use this instead of the current system? (0-10) | Scale | Adoption |

**Good practice:** one idea per question; no leading questions; mix closed (quantitative) and open
(qualitative) questions; pilot it first; ask for no more personal data than you need.
