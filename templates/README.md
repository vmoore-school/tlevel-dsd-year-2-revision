# Templates

Blank, reusable documents. **Copy them into `student-workspace/` before filling them in**, so the
originals stay clean for the next person.

| Folder | Contents | Used in |
|---|---|---|
| [`osp-evidence/`](osp-evidence/) | Proposal, test strategy, test log, assets log, AI prompt log, development log, feedback plan, evaluation | OSP Tasks 1 to 3b |
| [`analysis/`](analysis/) | Requirements specification, traceability matrix, user stories, risk register, skills audit | Subject 01, 02 |
| [`design/`](design/) | Data dictionary, style guide, wireframe annotation, algorithm design | Subject 04 |
| [`research/`](research/) | Research notes, source evaluation, survey, observation record, interview script | Subject 03 |
| [`collaboration/`](collaboration/) | Code review checklist, pull request template, meeting notes | Subject 05 |
| [`maintenance/`](maintenance/) | Changelog, release notes, change request, bug report, deployment checklist, user guide | Subject 06, 08 |
| [`placement/`](placement/) | Placement logbook and hours tracker | Subject 09 |
| [`lesson-template.md`](lesson-template.md) | Starting point for writing a new lesson's teaching notes | Contributors |

**Spreadsheets** are stored as `.csv` so they diff cleanly in Git and open in Excel, Google Sheets or
LibreOffice. Some contain formulas (e.g. the risk register score `=E2*F2`) that work once the file is
opened in a spreadsheet app. Save as `.xlsx` if you want to keep formatting.
