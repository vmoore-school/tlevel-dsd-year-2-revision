# 04 Command Words & General Competencies

From Appendix 1 of the specification. The command words were met in the Year 1 exams. In the OSP they
appear in task wording, and they tell you how deep each piece of writing has to go.

## Command words

| Command word | What it means | In the OSP |
|---|---|---|
| Give / state / name | Provide a response (a feature, characteristic, use or justification) | Short answers in logs |
| Identify | Select the correct answer from the context | Identify risks, requirements |
| Write | Write code from the given context | Task 2 |
| Describe | Responses linked in a logical order | Describe the proposed solution |
| Explain | A point plus a linked justification | Explain design choices |
| Explain with additional justification | A point, a justification, and a further justification of that justification | Justify language, platform or methodology choices |
| Discuss | Consider opposing aspects in context; no conclusion needed | Weigh up options in the proposal |
| Evaluate | Weigh strengths and weaknesses in context and **reach a supported judgement** | Task 3b |
| Draw | Produce a diagram (algorithm, process flow) | Flowcharts, DFDs, ERDs |
| Complete | Fill in the missing information in a diagram | Templates |

**Writing frame for "evaluate":** Point (criterion) → Evidence (feedback, test result, KPI value) →
Judgement (how well it is met) → Improvement (a justified next step). End with an overall conclusion.

## General competencies

The specification maps these to the OS content. Lesson READMEs show which apply.

**English:** E1 convey technical information to different audiences · E2 present information and ideas ·
E3 create texts for different purposes and audiences · E4 summarise · E5 synthesise · E6 take part in
and lead discussions

**Maths:** M1 measure with precision · M2 estimate, calculate, spot errors · M3 proportion · M4 rules and
formulae · M5 process data · M6 data and risk · M7 mathematical diagrams · M8 communicate using maths ·
M9 cost a project · M10 optimise work processes

**Digital:** D1 use digital technology and media effectively · D2 design, create and edit documents and
media · D3 communicate and collaborate · D4 process and analyse numerical data · D5 be safe and
responsible online · D6 code and program
