# Sample Data

Fictional datasets used across lessons. Everything is set in the same scenario (a community sports
club, see [`mock-briefs/brief-01`](../mock-briefs/brief-01-community-sports-club.md)), so students can
reuse them from analysis through to evaluation. All names and data are invented.

| File | Rows | Used for |
|---|---|---|
| `feedback-responses.csv` | 40 | Task 3a/3b practice: analysing survey feedback with pandas, evaluating against KPIs (lessons 00.04, 00.05, 03.02) |
| `sales-data.csv` | 72 | Dashboards and data visualisation, SQL aggregate practice (06.10, 06.04) |
| `support-tickets.csv` | 12 | Systematic issue resolution, triage, communication (08.04) |
| `api-response-example.json` | n/a | Parsing JSON from an API, nested data, pagination (06.05) |

The datasets were generated by a seeded script, so the patterns are deliberate. For example, mobile
users rate the layout lower, and cricket bookings are seasonal. Ask students to *find* these patterns.
