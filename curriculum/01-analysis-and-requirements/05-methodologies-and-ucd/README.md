## What must be taught

| ID | Status | Requirement |
|---|---|---|
| 01.05.01 | 🟥 | Agile: sprints, epics, stories, spikes; incremental delivery; changing requirements; light documentation |
| 01.05.02 | 🟥 | Scaled Agile: adds product increments, cohesive reporting, final stability iteration |
| 01.05.03 | 🟥 | Waterfall: rigid, artefact-measured, high initial cost, heavy documentation, limited client interaction |
| 01.05.04 | 🟥 | Rapid Application Development (RAD): prototypes, features first, code reuse, small-medium projects |
| 01.05.05 | 🟥 | Lean: eliminating waste, decide late, short cycles, fit-for-use iterations, small teams |
| 01.05.06 | 🟥 | Selecting and justifying a methodology for a given brief |
| 01.05.07 | 🟥 | User-Centred Design: who/what/how/when/why/experience; empathetic, iterative, interdisciplinary |
| 01.05.08 | 🟥 | UCD stages: understand context, specify requirements, design, assess against requirements |
