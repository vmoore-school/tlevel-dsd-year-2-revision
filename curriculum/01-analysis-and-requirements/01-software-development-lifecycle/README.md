| ID | Status | Requirement |
|---|---|---|
| 01.01.01 | 🟥 | Research & familiarisation: client brief, market context, common problems/risks, current hardware/software, emerging tech, existing solutions, guidelines/regulations |

| 01.01.03 | 🟨 | Planning & requirement analysis stage (detail in lessons 02 and 06) |
| 01.01.04 | 🟥 | Performing a user analysis with business analysis models (detail in lesson 03) |

| 01.01.06 | 🟨 | Developing & testing: prototype; module, system integration, automated and user testing |
| 01.01.07 | 🟥 | Deploying/implementing: install, configure, update, document iterations, version control |
| 01.01.08 | 🟨 | Maintenance: system support, user support, bug fixing, user training, releasing updates |
| 01.01.09 | 🟥 | The value of the digital product to the organisation and the role of the SDLC |
