## What must be taught

| ID | Status | Requirement |
|---|---|---|
| 00.03.01 | 🟥 | Develop a functional prototype in two+ languages from your own Task 1 designs |
| 00.03.02 | 🟥 | Evidence of iterative development: versioned builds, commit history, documented changes |
| 00.03.03 | 🟥 | Iterative testing and a test log (inputs, calculations, validation, processes) with retests |
| 00.03.04 | 🟥 | Content & assets log: source, description/purpose, date retrieved, licence |
| 00.03.05 | 🟥 | Code maintainable by a third party: comments, modularity, conventions, README |
| 00.03.06 | 🟥 | Submitting code as PDF and .txt as well as the working prototype |
| 00.03.07 | 🟥 | What markers reward: modular structure, classes/functions, defensive programming, exception handling, minimal globals, constants, consistent style; avoid pages of nested IFs and copy-pasted code |

- Build the starter project feature-by-feature, logging each iteration
- Refactor a 'nested-if' code sample into a modular one and explain the improvement
