# 00.01 Understanding the Occupational Specialism Project

> **Subject:** OSP Assessment Skills & Exam Technique  
> **Spec reference:** Scheme of Assessment (spec s4, p81-83); s5 grading  
> **Performance Outcomes:** PO1-PO6  
> **Used in OSP:** All  
> **Topic status:** 🟥 10

Key: ✅ known from Year 1 (revise only) · 🟨 partially known (extend) · 🟥 new (teach from scratch)

## Assumed prior knowledge (Year 1)

- Core grading (A*-E, UMS) from Year 1 - this is the other half of the T Level grade

## What must be taught

| ID | Status | Requirement |
|---|---|---|
| 00.01.01 | 🟥 | Structure: one synoptic project, 50h30m supervised, 144 raw marks, 50% of the overall T Level |
| 00.01.02 | 🟥 | The four tasks: Task 1 analyse & design, Task 2 develop, Task 3a gather feedback, Task 3b evaluate feedback |
| 00.01.03 | 🟥 | Performance Outcome weightings: PO1 24 (16.7%), PO2 57 (39.6%), PO3 18 (12.5%), PO4 9 (6.3%), PO5 18 (12.5%), PO6 18 (12.5%) |
| 00.01.04 | 🟥 | Grading: Distinction / Merit / Pass / Unclassified - raw marks, not UMS; boundaries set each series |
| 00.01.05 | 🟥 | Conditions: supervised + controlled sessions; internet allowed in all tasks except Task 3b; work kept securely between sessions |
| 00.01.06 | 🟥 | You cannot edit evidence from a previous task once it is submitted |
| 00.01.07 | 🟥 | Generative AI rule: Task 1 Activity C expects AI for short code snippets of specific functionality only - never the whole solution; prompts must be shown and outputs reviewed |
| 00.01.08 | 🟥 | Authentication, citing work that is not your own, and what tutors may / may not help with |
| 00.01.09 | 🟥 | Portfolio of evidence submitted electronically; file naming conventions (TaskX_DocName_RegNo_Surname_Initial) |
| 00.01.10 | 🟥 | Overall T Level: need Core grade E+ AND OS Pass AND 315-hour industry placement |

## Suggested activities

- Card sort: match each piece of evidence to the task and PO it earns marks for
- Calculate: if PO2 is 39.6% of marks, how should 50.5 hours be prioritised?
- Set up your mock-OSP folder in student-workspace/ using the official naming convention
