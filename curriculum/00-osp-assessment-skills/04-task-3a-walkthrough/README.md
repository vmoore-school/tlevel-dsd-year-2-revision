## What must be taught

| ID | Status | Requirement |
|---|---|---|
| 00.04.01 | 🟥 | Prepare demonstrations for a technical audience (e.g. developers) and a non-technical audience (client, users) |
| 00.04.02 | 🟥 | Write a feedback-gathering plan: who, how, when, what questions, how recorded |
| 00.04.03 | 🟥 | Gather feedback using appropriate methods (survey, interview, observation, focus group, usage data) |
| 00.04.04 | 🟥 | Record feedback in a format suitable for analysis (structured, quantitative + qualitative) |
| 00.04.05 | 🟥 | Unsupervised time may be used to collect feedback from people outside the centre |

## Suggested activities

- Record a 3-minute screencast demo for a non-technical client, then a 3-minute technical walkthrough
- Design a 10-question survey with a mix of Likert and open questions
