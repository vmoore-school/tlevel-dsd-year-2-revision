# Interactive Study Guide (planned)

This folder will hold the interactive version of the guide: a static site or web app built from the
lesson content in `curriculum/`.

## Planned features
- Lesson pages generated from each lesson's `README.md` and `notes.md`
- Self-marking quizzes per lesson (retrieval practice)
- A progress dashboard driven by the same topic IDs as `CHECKLIST.md` (e.g. `01.05.03`)
- Flashcards from each lesson's key terms
- Embedded code playgrounds for the Python/JS/SQL exercises
- An OSP countdown and task-by-task planner

## Content contract
So the site can be generated automatically, keep to these conventions in lesson folders:
- `README.md`: requirements (generated by `tools/build_curriculum.py`; keep the ID table intact)
- `notes.md`: teaching notes (from `templates/lesson-template.md`)
- `quiz.md`: questions as `1. Question` followed by `- [ ] wrong` / `- [x] right` options
- `resources/`: files the lesson links to
