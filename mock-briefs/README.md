# Mock Briefs

Original practice scenarios in the style of the OSP set task. They are **not** Pearson materials. Use
them for mock OSP runs and as context for lesson activities.

| Brief | Length | Use |
|---|---|---|
| [01 Riverside Community Sports Club](brief-01-community-sports-club.md) | Full (Tasks 1 to 3b) | Main running example: sample data and starter code use it |
| [02 Pawsitive Vets](brief-02-veterinary-practice.md) | Short | Second mock or lesson exercises |
| [03 Northgate Community Food Bank](brief-03-food-bank.md) | Short | Second mock or lesson exercises |

To contribute a brief, follow the structure of brief 01: a set task brief, then activities for each task.
